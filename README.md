# TinyWins

TinyWins is a small Java Swing desktop app for saving everyday moments worth celebrating. Add a short win, an optional note, and how it felt. Entries can be edited or removed.

## Run

Open a terminal in the `TinyWins` folder and run:

```text
javac Mood.java WinEntry.java TinyWinsApp.java
java TinyWinsApp
```

The app uses only Java's built-in Swing and standard library. Entries are held in a basic array and are cleared when the app closes.
